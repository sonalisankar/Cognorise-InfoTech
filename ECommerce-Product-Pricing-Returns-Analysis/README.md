# E-Commerce Product Pricing & Returns Analysis

## Project Overview
This project analyzes e-commerce product pricing, category performance, shipping factors, and product return patterns using SQL and Power BI. The goal is to identify pricing trends, evaluate product performance, examine return behavior, and generate insights that can support better business and inventory decisions.

## Business Objectives
- Analyze product pricing and category-level performance.
- Evaluate product data quality and consistency.
- Identify products with higher return activity.
- Rank products based on performance metrics.
- Benchmark return rates across product categories.
- Explore relationships between pricing, shipping, and product returns.

## Tools & Technologies
- **SQL:** Data validation, transformation, analysis, ranking, and benchmarking.
- **Power BI:** Dashboard development and business intelligence visualization.
- **SQL Server:** Database querying and analysis.

## Project Workflow

### 1. Data Validation
Reviewed product data quality and checked the consistency of key fields used in the analysis.

### 2. Category & Product Analysis
Analyzed category-level performance and evaluated individual product metrics.

### 3. Returns Analysis
Examined product return patterns and developed return benchmarking metrics.

### 4. Product Ranking & Benchmarking
Ranked products and compared return performance across categories.

### 5. Pricing & Shipping Exploration
Explored pricing, shipping, and returns to identify potential patterns affecting e-commerce performance.
